AI가 일하는 시스템을 만드는 개발자

AI를 쓰는 개발자가 아니라, AI가 일할 수 있는 시스템을 만드는 개발자

15년간 프론트엔드를 하며 가장 시간이 많이 드는 일을, AI가 규칙에 맞게 일하고 스스로 검사까지 마치는 프로그램으로 만들었습니다. 디자인 시안에서 화면 코드, 모션, 화면 동작까지 이어지고, 결과는 검사를 통과한 뒤에만 완료로 보고합니다.

작업 자동화 프로그램 설계·개발AI에게 일을 맡기는 지시문(프롬프트) 설계Codex · Claude Code · Antigravity 연동빌드·화면·접근성 자동 검사내 PC에서 안전하게 실행
  • 3종직접 만든 자동화 프로그램
  • 1,977개모션 샘플 · 코드 8종으로 내보내기
  • 5가지퍼블리싱 지원 환경 · Vue · React · HTML 외
  • 16개모션 분류 (3D·스크롤·호버·텍스트 등)

디자인 시안 한 장에서 시작해 화면 코드, 임시 서버(Mock API), 모션, 빌드·접근성·반응형 검사까지 이어지는 작업을 프로그램으로 자동화했습니다. 빠르게 만드는 것만이 목표가 아니라, 기존 프로젝트의 구조와 규칙을 지키고 검사 결과를 있는 그대로 알려 주도록 만든 점이 핵심입니다.

Publishing Agent운영 중

퍼블리싱 자동화 프로그램

디자인 시안 → 화면 코드

디자인 이미지를 올리면 기존 프로젝트의 구조와 규칙에 맞는 화면 코드를 만들고 검사합니다.

지원 환경
VueNuxtReact · Next.jsHTML · jQuery · SCSS메일 HTML
  • 한 번에 최대 10장을 순서대로 처리하고, 실패한 항목만 다시 실행
  • 간격·글자 크기·색상 같은 디자인 규칙을 프로젝트별로 최대 100개 등록해 시안과 일관되게 생성
  • 기존 프로젝트 보호: 패키지 자동 설치, Git 커밋·푸시, 배포, 자동 되돌리기는 하지 않음
  • Node.js 기반이며 Playwright로 실제 브라우저 검사, 데스크톱 앱(Electron) 구성도 포함
Frontend Agent구축 중

프론트 개발 자동화 프로그램

화면 설명서 → 화면 동작 + 임시 서버

화면 설명서를 바탕으로 화면 동작과 임시 서버(Mock API)까지 만들어, 실제 서버가 나오기 전에도 프론트를 완성하고 검증합니다.

지원 환경
Vue (JavaScript · TypeScript)HTML · Ajax임시 서버 4가지 상황
  • Vue(JavaScript·TypeScript)와 HTML/Ajax 프로젝트를 수정 없이 읽기만 해서 분석
  • 임시 서버는 성공·빈 값·오류·지연 4가지 상황으로 제공하고, 실제 서버가 나오면 주소만 바꿔 연결
  • 작업 전후 파일을 비교해 계획에 없는 변경을 찾아내고, 정해지지 않은 항목은 추측하지 않고 '미해결'로 보고
  • 퍼블리싱 프로그램과 코드를 섞지 않는 독립 프로그램 (외부 패키지 없이 Node.js 기본 기능만 사용)

05 · 신뢰 기준

믿고 쓸 수 있게 만든 방식

  • 검증 우선프로그램이 정상 종료됐다는 사실만으로 성공이라 보지 않고 결과 파일로 확인합니다. 실행하지 못한 검사는 '통과'가 아니라 '미실행'으로 보고합니다.
  • 기존 프로젝트 보호승인된 범위 밖의 변경, 이미 수정 중이던 파일, 패키지·잠금 파일은 건드리지 않습니다.
  • 안전한 실행내 PC(127.0.0.1)에서만 열고, 비밀번호·키·개인정보를 코드와 기록에 남기지 않습니다.
06 · 한 사람의 작업 범위

한 명으로 충분한 이유

시안을 받은 시점부터 화면이 동작하는 상태로 넘기기까지의 과정을 혼자 이어서 수행합니다.

  • 퍼블리싱HTML·SCSS 퍼블리싱, 웹 표준·접근성·반응형·크로스브라우징
  • 프론트 개발Vue 3 중심 SPA, 컴포넌트 설계, 상태 관리, REST API 연동
  • 모션·인터랙션GSAP·CSS·Canvas 인터랙션, 마이크로 애니메이션
  • 임시 서버(Mock API)서버 없이 화면 완성, Node로 임시 API 서버 직접 구현
  • 검증·문서접근성·반응형 검사, 가이드 문서화
  • 백엔드 (초급)백엔드는 VO·DTO 정의와 API 연동까지 직접 다룹니다. Node 기반 API 서버(회원·예약·결제 모의·환불·후기)를 구현했고, Spring Boot 구조 설계도 진행하고 있습니다.
